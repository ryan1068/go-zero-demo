# 拾光严选商城视觉改造设计

日期：2026-10-18
状态：已实现

## 目标

将现有商城 C 端改造为「国潮胭脂风」的淘宝式商城，统一品牌名、标题、配色、商品卡、登录注册页和商城各页面；不修改后端接口、数据库和服务端口。

## 品牌

- 名称：拾光严选
- Slogan：把好物收进时光里
- 中文衬线标题 + 无衬线正文
- 印章式「拾光」Logo

## 配色

| 用途 | 色值 |
|---|---|
| 主色 | `#A33B4A` 胭脂 |
| 深色 | `#2E2326` 墨色 |
| 金色 | `#C9A86A` |
| 背景 | `#F7EFF0` 胭脂白 |
| 卡片 | `#FFFEFA` 暖白 |
| 辅助文字 | `#8A7A7D` |

2026-10-18 调整：品牌名由「拾光优选」改为「拾光严选」，主色最终确定为胭脂红 `#A33B4A`。

## 页面

- 首页：分类栏 + 国潮 Banner + 限时好物 + 精选商品
- 商品列表：分类筛选、搜索、排序、商品网格
- 商品详情：图集、价格面板、服务承诺、加购/购买
- 购物车：商品行、数量、选中、吸底结算
- 结算：地址卡片、商品清单、金额汇总
- 订单列表/详情：状态 Tab、订单卡片、状态与物流
- 收货地址：卡片式地址、默认地址印章
- 登录/注册：左侧品牌展示 + 右侧表单
- 管理后台：墨色侧边栏 + 胭脂选中态，功能不变
