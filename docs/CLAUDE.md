# 文档规范

## 文档位置

```
docs/
├── DEVELOPMENT_PROCESS.md   # 开发流程
├── adr/                     # 决策记录
└── superpowers/             # 设计 / 计划
```

## API 文档

- `.api` 文件是接口事实来源
- 接口描述写在 `.api` 注释中
- 请求/响应字段必须有说明

## 代码注释

- Go：公开函数/类型必须有 godoc 注释
- Vue：复杂逻辑加注释
- 注释语言与现有代码保持一致（中文）

## 禁止事项

- 无意义的注释（如 `// 获取用户` 对应 `func GetUser`）
- 提交过期文档
- 在代码中写大段文档（放 `docs/`）
